Extreme Dreams

Case Study

Extreme Dreams was a shelved Headgames Studio project. I designed the characters and the world and contributed to the story development. The project was never released and the studio closed not long after.

This is a personal experiment revisiting that buried material with 2026 AI tools. The goal: see how far current image models can push a lost game-world aesthetic — preserving the original design language while translating the rendering itself from painted illustration into modern dimensional CG.

This page is a living document. Assets get added as the experiment continues, character by character, environment by environment.

Tools GPT Image 2 · Nano Banana 2 · Magnific · Midjourney 8.1 · Photoshop
