Kling 3.0 Native 4K Test

Kling released Native 4K Direct Output on Kling 3.0 while this reel was already in final assembly. After wrapping, I ran a few clips through the 4K pipeline using 4K source images to see what the native engine resolves. The source images weren't dialed to production-level — this was a pure resolution test. My read: 4K source through a native 4K engine preserves all the fine detail of the source images. The better the 4K source quality, the better the output — this is detail an upscaler can't add.
