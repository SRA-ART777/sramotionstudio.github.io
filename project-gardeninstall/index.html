Garden Install

Landscape • Lighting Design

A residential garden installation visualized across four times of day — morning, noon, sunset, and night — showing how landscape lighting design transforms the same space from functional daytime garden to dramatic nighttime environment. Built from a single source photograph using Nano Banana Pro for relighting and environment generation, animated with Kling for natural movement across each scene.
